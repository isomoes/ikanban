# `@isomoes/dsh-ikanban-ui-workspace`

Locally owned iKanban workspace and session browser. It controls workspace
selection, session grouping and search, and directory picking flows.

`src/client.js` is the tracked customization source, initially vendored from
`@deepseek-ai/dsh-client-ui-workspace@0.1.0-rc.6`. Run `pnpm build` after
editing it to refresh `lib/client.js`.
