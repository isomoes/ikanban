# `@isomoes/dsh-ikanban-ui-layout`

Locally owned iKanban web layout shell. It controls the root three-column
frame, responsive panel geometry, drag handles, and the `ctx.layout` service.

`src/client.js` is the tracked customization source, initially vendored from
`@deepseek-ai/dsh-client-ui-layout@0.1.0-rc.6`. Run `pnpm build` after editing
it to refresh `lib/client.js`.
