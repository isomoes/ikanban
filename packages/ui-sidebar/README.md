# `@isomoes/dsh-ikanban-ui-sidebar`

Locally owned iKanban sidebar shell. It controls branding, sidebar collapse,
the New Session action, and the seats used by workspace and settings plugins.

`src/client.js` is the tracked customization source, initially vendored from
`@deepseek-ai/dsh-client-ui-sidebar@0.1.0-rc.6`. Run `pnpm build` after editing
it to refresh `lib/client.js`.
